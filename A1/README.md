# 苏醒园地 · A1 陶土暖园

这是独立可编辑的 **Godot R3 完整原生工程**，保留完整分辨率模型与纹理，已包含农民角色、骨骼、待机/行走动画及场景细化。

## 打开与运行

1. 在 Godot 4.7.2 的项目管理器中导入本文件夹的 `project.godot`。
2. 首次打开等待模型和字体导入完成。
3. 按 **F5** 运行，默认进入 A1。无需另一风格文件夹、Lux3D、API Key 或网络服务。

此工程的场景美术通过脚本在运行时组装。因此编辑器未运行时可能显示基础灰盒；F5 后会加载完整模型和地表细节。

## 操作

WASD 移动；Shift 加速；E 开垦/播种/浇水/收获；T 推进时间；
1/2 切种子；右键拖动旋转镜头；滚轮缩放；Esc 暂停；R 重开；H 返回安全位置。

## 工程结构

- `project.godot`：独立工程入口，主场景指向 `art/refinement-r3/A1/play.tscn`。
- `main.tscn`、`scripts/`：完整玩法、角色控制、交互、作物逻辑、HUD。
- `art/production/`：模型加载与基础美术组装。
- `art/refinement-r3/`：本风格的地面、悬崖、残墙、植被、天空和道具细化。
- `art/farmer-r1/`：农民完整来源链、清理后的蒙皮模型、角色适配脚本。
- `art/experiments/`：本风格所需的基础模型、原始来源、局部优化模型和继承场景。
- `fonts/`：中文字体及其许可证。
- `docs/`：概念参考、实机预览和独立工程验证结果。
- `tools/`：资产校验值更新与独立回归工具。

模型材质和纹理嵌入 `.glb` 文件，可用 Blender 或其他支持 GLB 的软件编辑。
若修改或替换某个已登记模型，运行 `python tools/update_asset_hashes.py --apply` 更新清单 SHA256，再运行游戏。
该命令只更新本工程 JSON 中已存在模型的校验值，不生成模型或联网。

## 验证

`python tools/validate_project.py --godot "你的Godot控制台程序路径"` 会运行当前工程的 61 项原生检查。
添加 `--headless` 可只验证玩法；默认有渲染截图。证据写入 `docs/validation/`。

## 分发边界

文件夹内包含运行和继续编辑所需的文件。未包含引擎安装程序、网页隧道程序、机器缓存、账号凭证和历史收费记录。
原始场景的三段式玩法布局保留；新版美术仍等待用户审阅，不将技术测试等同于美术验收。
